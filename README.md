# 食衡 Shíhéng

面向澳洲多元文化饮食场景的中英双语营养记录产品验证项目。

## 项目资产

- `澳洲饮食营养健康App可行性研究报告.docx`：中国大陆同类产品研究、澳洲市场与监管可行性分析。
- `mobile/`：基于 Expo、React Native、TypeScript 与 Expo Router 的跨平台 MVP。

## 当前进度

- 已完成产品可行性研究报告。
- 已搭建 iOS、Android 与 Web 共用代码的移动端工程。
- 已实现今日概览、双语食品搜索、食物详情、份量调整、餐次记录、日志和目标设置。
- 已实现自定义食品、收藏、复制记录、首次引导、隐私说明、本地反馈、离线底库和个人图鉴。
- 已加入开发样例数据、来源可信度提示、本地持久化和非医疗用途边界。
- 已通过 TypeScript 检查、领域测试、30个Web静态路由生产导出及手机视口核心流程验收。
- 安卓侧已接入正式包自动更新通道，并关闭系统备份以保证卸载清除本机数据。
- 非商业封闭测试综合就绪度约66%，详细评估见 `mobile/NONCOMMERCIAL_READINESS.md`。

## 开始开发

```powershell
cd mobile
pnpm install
pnpm start
```

详细说明、数据原则与后续路线见 `mobile/README.md`。
